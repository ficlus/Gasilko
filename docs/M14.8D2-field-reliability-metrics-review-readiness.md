aggregation; timeline unique(incident_id,sequence) does not index recorded_at/org;

- incident_reliability_transport_events: (entity_id,organization_id,created_at DESC,id), partial INCIDENT / INCIDENT_TASK.

most201 (keep200); deliveries at most2001 (keep2000) across those event IDs.

deterministic event UUID/id order within the chosen events. Counts are sampled,
not totals when a cap is reached. No full context, task DTO, map geometry, NAV
route, SIM runner, per-actor loop, extra RPC per row or analytics write hook.
Actual query planner/index selection, existing table volume/index build cost
